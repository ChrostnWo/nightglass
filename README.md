# Nightglass

A local-first markdown vault in the browser. Notes, folders, and the link graph stay on your device.

## Features

- Nested folders and markdown notes
- Wikilinks (`[[Note]]`), tags, and a graph view
- Edit, read, and split layouts
- Command palette, checklists, and five themes
- A sample vault you can restore at any time

## Develop

```bash
npm install
npm run dev
```

Open the app at `http://localhost:8080`.

## Stack

React 19, TanStack Start, Tailwind CSS, and Zustand.
